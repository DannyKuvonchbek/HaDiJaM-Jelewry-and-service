# HaDiJaM AI features

The public Concierge is a deterministic, database-backed site assistant. It searches only active public products and services and builds localized answers from those records. It does not call an external AI provider, send visitor questions off-site, or read private member/order/booking data. Signed-in conversation history is stored in HaDiJaM's database.

Admin product review remains a separate provider-backed feature. It requires server-side AI provider configuration and is not part of the public catalog Concierge.
